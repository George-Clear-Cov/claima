# Activate Microsoft Co-Sell + ISV Success (post-publish checklist)

> Claima — AI Revenue Cycle Management is **LIVE on Microsoft Marketplace** (published 2026-07-20;
> co-sell "In Market"). Publishing set the table — now *you* drive engagement. Work these in order.
> Microsoft doesn't auto-assign a rep to a list-only ISV; the relationship grows from your outreach + traction.

## 1. Book your ISV Success benefits (fastest human touchpoint)
- [ ] Partner Center → **Benefits → ISV Success** → book the **technical consultations / "connect with
      an expert"** sessions (cloud architecture, security, marketplace-listing optimization). These are
      1:1 sessions with Microsoft experts — the quickest way to a real person.
- [ ] Redeem the **Azure credits** included with ISV Success (fund Azure workloads — App Insights, Blob
      for EDI archive, etc. — which also builds attributable Azure consumption for the MS Startups milestones).

## 2. Activate Marketplace Rewards (co-marketing, now that you're published)
- [ ] Partner Center → **Marketplace Rewards** (unlocks once an offer is live). Claim the benefits tier
      you qualify for — listing optimization, co-marketing assets, and (at higher tiers) a marketing advisor.
- [ ] Watch for the **automated Marketplace Rewards / partner-nurture emails** now hitting your inbox +
      the Partner Center **notifications bell** (you had 1 unread) — some contain benefit activations.

## 3. Register co-sell opportunities (this is what pulls in a Microsoft seller)
- [ ] Partner Center → **Referrals** workspace → **New deal / co-sell opportunity**. Co-sell is
      **deal-driven**: when you have a live prospect (esp. one already on Azure), register it here to loop
      in a Microsoft field seller who's comped to help close it. Don't wait for spontaneous outreach.
- [ ] Make sure the offer's **Co-sell with Microsoft** listing is complete (solution overview, a customer
      one-pager / pitch deck) so sellers can represent you. (Status already "In Market".)

## 4. Reach the Microsoft Health & Life Sciences ISV team (your vertical)
- [ ] Your HIPAA + Bedrock + healthcare profile is exactly their ISV wheelhouse. Reach them via the
      **Microsoft partner community**, a **health-tech Microsoft event** (HLTH/ViVE/Ignite), or your
      **Microsoft for Startups** contact. Ask to be connected to a **Health & Life Sciences PDM**.

## 5. Longer-term co-sell depth
- [ ] Pursue **IP Co-sell eligible** status (needs a transactable offer + solution validation) — see the
      transactable/MACC playbook. Unlocks the strongest co-sell incentives; do it when a transactable
      offer is warranted.
- [ ] As Azure consumption + marketplace activity grow, you become eligible for a **dedicated ISV Success
      Engagement Manager** (invitation-based on performance/intent-to-transact).

## The mindset
Publish + ISV Success + co-sell "In Market" = the table is set. **A rep relationship is earned via your
outreach + traction, not a queue.** Book the consultations, activate Rewards, and register real deals as
co-sell opportunities — that's what makes a Microsoft human show up.
